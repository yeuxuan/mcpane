# ADR-008：竞品仅作功能和架构参考

- 状态：Accepted
- 日期：2026-07-11（2026-10-28 修订：更正许可证事实，补 MIT 派生义务）

## 背景

CC Switch（MIT 许可）与 MCP Router 是功能上最接近的开源项目。
参考它们能显著降低产品与架构探索成本，但直接复用会引入许可证与原创性风险。

## 决策

1. 对竞品**只研究**：公开功能、交互流程、模块边界、失败场景、架构思路。
2. **不复制**：源代码、函数、组件、文案、视觉资源、独特目录结构。
3. 官方 MCP 规范、Claude Code / Codex 官方文档优先级高于任何竞品实现；
   冲突时以官方为准。
4. 参考清单集中记录在 `docs/competitors/REFERENCES.md`，
   新增参考必须先更新该文件。
5. 个别数据性内容（如供应商预设数值）若与某竞品的公开数据同源，视为
   **MIT 派生**：须在仓库显著位置（README 致谢节 / THIRD-PARTY-NOTICES）
   保留对方版权与许可证声明，不得在没有署名的情况下分发。

## 理由

- 保持 MCPane 代码库的许可证纯净与独立可审计性；
- 竞品实现可能偏离规范（例如 Bridge 默认化），不应继承其历史包袱；
- MIT 允许派生与移植，条件是保留版权与许可证声明——署名义务必须落实，
  而不是假设「宽松许可 = 无义务」。

## 后果

- Code review 需检查可疑相似实现；
- 与竞品行为对照的差异点须写入 ADR 或 REFERENCES.md 的"改进原则"；
- 与竞品数据同源的部分必须在 README 致谢节声明来源与许可证。
