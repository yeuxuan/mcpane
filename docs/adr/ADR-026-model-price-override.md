# ADR-026：按模型的价格覆盖

- 状态：Accepted
- 日期：2026-10-04
- 关联：ADR-022（本地路由）、`docs/competitors/REFERENCES.md`（magpie 的成本与价目覆盖）

## 背景

用量页的成本是读取时按 `usage_events.model_key` LEFT JOIN `model_pricing` 估算的。价目表（种子 + models.dev 同步）
查不到的模型——部分中转站的专属模型——成本显示为 `$0` 并标「无定价」，用户没有办法自己补价。

magpie 提供「按供应商 / 模型覆盖价目」。我们先核对了前提，**按供应商的倍率在本项目里做不出来**：

- `usage_events` 没有供应商列，会话文件里也没有 base_url / provider；
- 历史事件无法补归属（切换历史是自由文本且 500 条轮转，见 `by_app` 的注释）；
- `usage_by_provider` 实际只按客户端聚合。

所以只做**按模型**的价格覆盖，并在界面与本文里把口径写明。

## 决策

### 1. 独立的覆盖表，整行生效

`model_pricing_override(model_id PK, input/output/cache_read/cache_creation_per_million TEXT)`（迁移 0027）。

- **不放进 `model_pricing`**：后者被 models.dev 同步 `INSERT OR REPLACE` 覆写，覆盖会被冲掉。
- **整行生效**而不是逐列回落：弹窗里四项都有明确的数，缓存两项不填就是 0。逐列回落会让「我填了 0」与「我没填」
  无法区分，且成本会悄悄混进官方价。
- 价格仍存十进制字符串（与官方价同形态防浮点漂移），`f64` 的 Display 是最短往返表示且不带指数记法。

### 2. 成本表达式只有一处

`COST_EXPR` / `FROM_JOINED` 同时 JOIN 官方价与覆盖，价格取 `COALESCE(覆盖, 官方, '0')`。总览、趋势、按模型、按应用、
按项目共用它，所以覆盖在所有维度同时生效，也**对历史事件同样生效**（成本本来就是读取时计算）。
`unpriced` 与 `priced` 把「有覆盖」算作有定价；按模型的行另带 `overridden` 供界面标「自定义」。

### 3. 校验

四项必须是有限数、`0 ≤ x ≤ 1,000,000`（美元 / 百万 token，挡手滑多打的零）；`model_id` 只接受**用量里出现过**的
`model_key`（不开放任意键，免得写进一个永远命不中的死行）。清除不存在的覆盖不报错。

### 4. 界面

用量页「按模型」每行有「设置价格」（无定价的行用强调色）；有覆盖的行显示「自定义」。弹窗给四个数字输入，有官方价时
再给「按官方价的倍率」快捷填充（`0.6` → 一键填出四项，可再手改）与「恢复默认」。弹窗与本文一致写明
**「按模型生效，不区分供应商」**：同一个模型无论走哪家供应商都按这个价估算。

### 5. 备份与同步

覆盖是用户配置，**跟着走**：本机备份整库快照自然包含；云同步不把它列入 `SYNC_LOCAL_TABLES`，换设备价格不丢。
导入按表动态枚举，新表无需改清单；`price_override_survives_local_backup_and_travels_with_cloud_sync` 守住这一点。

## 不做

按供应商 / 按时间窗归属；导入导出价目表；给尚未出现在用量里的模型预设价格（见 §3）；覆盖「窗口 / 上下文长度」
（magpie 另有，与成本无关）。

## 验证

- 存储层：覆盖优先于官方价且清除后回落；给价目表没有的模型补价后 `unpriced` 清零；五个聚合维度都用覆盖价；
  Codex 的缓存扣减口径在覆盖下不变；models.dev 同步不动覆盖；非法数值与未出现过的模型被拒；十进制往返。
  做过反向验证：把 `COALESCE` 顺序倒回去 / 让 `unpriced` 忽略覆盖，对应测试必然变红。
- 前端：校验与倍率纯函数单测；Playwright（mock IPC）覆盖无定价行填价、倍率套用、恢复默认、非法输入禁用保存。
- **未验证**：桌面应用里点击「设置价格」的完整界面流程（Tauri 开发构建无法被自动驱动，只有 Playwright mock）；
  Windows。已写入发版清单。
