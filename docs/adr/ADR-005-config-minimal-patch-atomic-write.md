# ADR-005：配置最小 Patch 与原子写入

- 状态：Accepted
- 日期：2026-07-11

## 背景

MCPane 会修改用户的 `~/.claude.json`、`.mcp.json`、`~/.codex/config.toml` 等
关键配置。这些文件同时被客户端与用户手工维护，任何"整体重建式"写入都可能
丢失注释、未知字段或并发修改。

## 决策

写入流水线（全客户端统一）：

```text
重新读取当前文件 → 解析 → 计算内容哈希 → 生成最小 Patch → 展示 Diff
→ 创建 Snapshot → 写入同目录临时文件 → fsync → 语法与业务验证
→ 原子替换 → 重新读取验证 → 写入操作历史
```

强制规则：

- 禁止对 JSON/TOML 做字符串搜索替换；禁止整体重建 Codex `config.toml`；
- JSON 未知字段必须保留；TOML 使用 `toml_edit` 做语法树级最小修改，
  保留注释、未知 Table 与非目标格式；
- 写入前文件哈希变化 → 中止并提示冲突（客户端原生配置是"实际状态"，
  数据库只是期望状态与历史，不得用过期快照无条件覆盖）；
- 写入失败自动恢复；回滚前再次备份当前文件。

## 后果

- 需要 `config_snapshots` / `config_operations` 表与失败恢复测试（TASK-200 起）；
- 每个 Adapter 的写入路径都必须走同一配置安全核心。
